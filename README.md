# 👻 [Nome do Jogo]

> Protótipo de um jogo 2D em pixel art sobre um fantasma que leva aos vivos as cartas deixadas por quem já partiu.

## 📜 Sobre o jogo

Nem tudo é dito em vida. Neste jogo, um fantasma recebe uma missão: entregar aos vivos as cartas deixadas pelas pessoas falecidas.

> ⚠️ Este projeto é um **protótipo**.

## 🎮 Como jogar

1. Baixe o arquivo `.zip` do jogo.
2. Extraia todo o conteúdo para uma pasta.
3. Execute o arquivo `new_blank.exe`.

## 🛠️ Tecnologias

- **Engine:** GameMaker
- **Linguagem:** GML (GameMaker Language)

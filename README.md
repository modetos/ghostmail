# GHOSTMAIL
Ghostmail é um jogo 2D de plataforma criado por mim para experimentar o ramo de gamedev e exercitar um pouco mais lógica de programação. O jogo foi feito na engine GameMaker usando a linguagem própria deles, a GML. Alguns assets são autorais, outros produzidos por criadores que disponibilzaram o conteúdo online.
